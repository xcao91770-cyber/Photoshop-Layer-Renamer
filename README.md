# 图层名称批量操作工具 (Photoshop & Spine Helper)

一款专为 2D 游戏美术、角色拆件与 Spine 动画师打造的 Photoshop 批量图层命名与规范排错工具。

---

## 核心功能

### 1. 规范检查（Spine 导出前质检）
- **重名图层排查**：自动统计全文档重名项并标注重名频次，彻底避免切片导出时静默覆盖。
- **空白废层/空组识别**：自动读取图层像素边界，精准揪出无像素透明层与空文件夹。
- **就地改错**：检查面板常驻不退，支持在列表中双击定位展开父组、就地删除废层、就地重命名。
- **一键全选异常**：一键在 PS 中全选所有空白废层，按 `Delete` 键秒清垃圾。

### 2. 多模式批量重命名（严格互斥）
- **五大模式**：支持前缀、后缀、保留原名追加编号、整名替换、查找替换。
- **编号插槽**：自由配置补零规格（01 / 001）、起始序号与连接符。
- **查找替换对照窗**：执行前以列表形式核对每一项修改前后名称，防止误伤。
- **图层组保护**：默认仅修改组本身，保护组内子图层不被污染。

### 3. 独立图层检索定位器
- 双列表格清晰显示图层名称与完整所属层级路径。
- 支持关键词即时过滤，双击自动展开各级父文件夹并高亮选中。

### 4. Spine 标签预设
- 内置 `[bone]`, `[slot]`, `[skin]`, `[merge]`, `[folder]` 等官方标签快捷填入。
- 支持将常用前缀/标签保存为个人自定义预设。

## 安装与使用方法

### 下载脚本
在仓库文件列表中，点击 **`图层命名批量修改.jsx`**，进入详情页后点击右上角的下载图标保存到电脑。

### 运行方式
- **方式一（临时运行）**：
  打开 Photoshop，点击菜单栏：`文件` ➔ `脚本` ➔ `浏览...`，选择下载的 `.jsx` 文件即可启动。
- **方式二（安装为常驻菜单，推荐）**：
  将 `图层命名批量修改.jsx` 复制到 Photoshop 的预设脚本文件夹中：
  - **Windows**: `C:\Program Files\Adobe\Adobe Photoshop [版本年份]\Presets\Scripts`
  - **macOS**: `/Applications/Adobe Photoshop [版本年份]/Presets/Scripts`
  
  重启 Photoshop 后，即可在 `文件` ➔ `脚本` 菜单下直接点击运行，也可以在 PS 的 `编辑` ➔ `键盘快捷键` 中为其绑定专属快捷键。
